Rules

Build the ten piles down in alternating colours; move any face-up run. Only a King, or a run headed by one, goes into an empty pile. Foundations build up by suit from Ace to King, two per suit; Aces go up by themselves. The Devil's Six go up only to the foundations, in order from the right. A deal puts one card on each pile, skipping piles that start with a face-up King. The stock is dealt once.

Open classic shows every card but face-down cards still cannot move. Open natural starts with every card face up, so any run can move, and a pile that is one run from a King at the bottom is skipped by deals.

Taking back a move is free if the move can be undone by another move; otherwise it counts 1, or the number of cards for a deal. "Winnable" means the deal can be won with every card known.

Hint, Still winnable? and Solve use the solver, which sees every card. They are recorded with the game; a game the solver finishes counts as solved, not won.
